# `tools/`

Build, publish, and maintainer helpers for MSBT.

| Path | Purpose |
| --- | --- |
| `build_sdkmod.ps1` | Pack `MattsSDKBoostingTools.sdkmod` from `mod_extracted/` |
| `build_electron_beta.ps1` | Build Electron installer / portable ZIP |
| `publish_github_release.ps1` | Upload release assets + notes |
| [`tests/`](tests/) | Automated checks (bridge, Quick Menu, etc.) |
| [`third_party/sdk_mods/`](third_party/sdk_mods/) | Bundled support mods (ActorScriptDeployer for Dev Spawner) |
| [`NearbyDump/`](NearbyDump/) | Optional BL4 folder mod for dumping nearby object paths |

Repo overview: [`docs/PROJECT_MAP.md`](../docs/PROJECT_MAP.md).
