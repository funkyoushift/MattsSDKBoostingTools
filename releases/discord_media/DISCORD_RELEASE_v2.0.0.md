## Post text (copy/paste)

```text
Matt's SDK Boosting Tools v2.0.0 is out.

Native in-game Quick Menu + full external editor. BLImGui is optional now.

Download (pick ONE):
https://github.com/funkyoushift/MattsSDKBoostingTools/releases/tag/v2.0.0
• MSBT-Installer-v2.0.0.exe  ← recommended
• MSBT-Portable-v2.0.0-win-x64.zip

Requires oak2-mod-manager v0.3:
https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3

────────────────
INSTALL
1) Install/update oak2-mod-manager v0.3
2) Install MSBT 2.0.0 (installer or portable)
3) Open MSBT → Updates → Install / Update SDK Mod
4) Fully restart Borderlands 4
5) Load into the world (menu-only is not enough)

────────────────
IN-GAME QUICK MENU
• F7 = open / close Quick Menu
• F6 = unstuck (restore mouse / GameOnly if stuck)
• Esc = close modal, then close menu

What you get:
• 5 pages × 12 slots
• Pin Last Command / Repeat Last Drop / Lock Player
• Edit mode: assign, clear, swap, reset page/all
• Works without BLImGui

────────────────
EXTERNAL APP — HOW TO PIN COMMANDS
1) Open the ★ Quick Menu tab
2) Or click a small + QM button next to supported actions (Boosting, Travel, Movement, Spawnables, Dev Spawner, etc.)
3) Choose page + slot → Save
4) Press F7 in-game — the slot is live (no restart)

SERIALS / BL4 CODES:
• Serial Tools → Bookmarks delivery → gold + QM Selected / All / Non-Host
• BL4 Codes → Delivery panel → same gold + QM buttons
• Check the rows you want first, then pin

────────────────
Please report bugs with:
• host or non-host
• lobby size
• exact button clicked
• selected target
• who received the effect
• screenshot / log if possible

Support MSBT:
• Tip FunkYouSHiFT: https://streamlabs.com/funkyoushift/tip
• Donate to Mattmab: https://ko-fi.com/mattmab
Site: https://www.funkyoushift.com/
```
