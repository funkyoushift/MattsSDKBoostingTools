## Post text (copy/paste)

```text
Matt's SDK Boosting Tools v2.0.0 is out.

Native in-game Quick Menu + full external editor. BLImGui is optional now.

Download (pick ONE):
https://github.com/funkyoushift/MattsSDKBoostingTools/releases/tag/v2.0.0
• MSBT-Installer-v2.0.0.exe  ← recommended
• MSBT-Portable-v2.0.0-win-x64.zip

Requires oak2-mod-manager v0.3:
https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3

────────────────
INSTALL
1) Install/update oak2-mod-manager v0.3
2) Install MSBT 2.0.0 (installer or portable)
3) Open MSBT → Updates → Install / Update SDK Mod
4) Fully restart Borderlands 4
5) Load into the world (menu-only is not enough)

────────────────
IN-GAME QUICK MENU
• F7 = open AND close the Quick Menu
• Esc = close a popup first, then close the menu
• Close F7 button in the menu also works
• F6 = UNSTUCK — force-closes the menu and restores normal mouse / look / move if your cursor gets stuck on screen after the menu

What you get:
• 5 pages × 12 slots
• Pin Last Command / Repeat Last Drop / Lock Player
• Edit mode: assign, clear, swap, reset page/all
• Works without BLImGui

────────────────
EXTERNAL APP — HOW TO PIN COMMANDS
Look for the gold/orange + QM buttons (close-ups in the pics):

1) Serial Tools → Bookmarks delivery → gold + QM Selected / All / Non-Host
2) BL4 Codes → Delivery panel (right) → same gold + QM buttons
3) Boosting / Travel / etc → small + QM next to supported actions
4) Choose page + slot → Save
5) Press F7 in-game — slot is live (no restart)

Check the rows you want first, then pin.

────────────────
Please report bugs with:
• host or non-host
• lobby size
• exact button clicked
• selected target
• who received the effect
• screenshot / log if possible

Site: https://www.funkyoushift.com/
```

## Short follow-up (optional)

```text
What F6 Unstuck means:
If the Quick Menu leaves your mouse stuck on screen or look/move feels locked, press F6. It force-closes the menu and puts input back to normal game control. Use F7 for normal open/close; use F6 only when something feels stuck.
```
