MSBT Quick Menu preview (for azzarock / testers)
Branch tip: cursor/quick-menu-native-umg-0b18
Package: MattsSDKBoostingTools-quick-menu-preview.sdkmod (also MattsSDKBoostingTools.sdkmod at repo root)

Important
- Quick Menu + external bridge do NOT use BLImGui.
- You do NOT need blimgui.zip for this preview.
- UIDevelopmentShowcase is NOT required.
- A legacy BLImGui panel may still load if the user already has blimgui installed; that path is optional fallback only and is not part of Quick Menu.

Install
- Drop the .sdkmod into Borderlands 4 sdk_mods (same as other SDK mods).
- Restart / reload mods, load into gameplay.

Quick Menu controls
- F7 : open / close Quick Menu
- F6 : unstuck (force-close menu + restore GameOnly input if cursor sticks)
- Console:
  - msbt_quick_menu
  - msbt_quick_menu_pin
  - msbt_quick_menu_repeat [player]
  - msbt_quick_menu_lock [on|off] [player]
  - msbt_quick_menu_unstuck

Locked behavior in this build
- Editable grid: up to 5 pages x 12 buttons
- Pin Last Command (basic + alias/custom label cycle in Edit)
- Repeat Last Drop: pick player at run time; optional Lock Player (option C)
- No extra danger confirms
- Action / serial-delivery toasts (banner in menu; non-blocking toast if menu closed)
- Target / Refresh party from menu chrome
- Edit: Swap With…, Reset Page, Reset All
- Bridge actions: repeat_last_drop, set_drop_player_lock, quick_menu_action
- Bridge /status includes last_command, last_drop, drop_player_lock

Not in this preview
- Loot pool work (on hold)

Smoke checklist
1) With blimgui.zip disabled/absent: F7 still opens Quick Menu
2) Escape/Close / F6 restore mouse to game
3) Target + Refresh update the selected player line
4) Edit -> assign/clear/swap slots; Reset Page / Reset All
5) Run a drop/delivery, Pin Last Command into a slot
6) Repeat Last Drop prompts for player unless Lock Player is on
7) Optional: bridge GET /status returns ok with last_command / drop_player_lock fields
