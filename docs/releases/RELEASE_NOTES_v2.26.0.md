# AFK boost amounts

- Choose character level, specialization level, cash, Eridium, and vault-card key amounts with desktop AFK sliders or exact-number inputs.
- Amounts are saved between sessions. Currency and keys are added on each join; keys apply to each of cards 1–5. Level targets do not reduce characters already above the selected target.
- Existing selections keep their maximum defaults. SDUs keep the 3,225-point option.
- Custom amounts require this release's SDK mod. Older game-side versions are detected before starting with custom amounts.
- Includes the community screenshots and folder improvements from v2.25.0.

Install the updated game files and restart Borderlands 4 to load the new SDK behavior. Stop and restart AFK after changing amounts.

Validation: automated targeted-action, input validation, saved-setting reload, desktop UI, and packaging checks. Live guest boost behavior was not retested for this release.
