# Borderlands 4 Modding Tools v2.29.1

Fixes reopening the control panel while remote access is enabled. The tray and a second app launch now always show the main panel, even when a hidden item-card rendering window exists.

Includes the v2.29.0 Community Folder and shared item-card improvements, lazy caching, concurrent manual/AFK delivery fixes and selected-installation SDK checks.

Uploaded screenshots and matching GZO images remain first. New game-generated cards require supported Steam build 25372571 in a solo session and show standalone stats. Missing artwork and unusually long modded layouts remain incomplete. No NCS calls are used by this card feature.

Android remains v1.5.0. Install the desktop update and matching SDK, then restart BL4.
