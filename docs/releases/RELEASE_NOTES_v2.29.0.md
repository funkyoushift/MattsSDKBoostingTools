# Borderlands 4 Modding Tools v2.29.0

Item cards now appear across Community Folders, saved items, catalogs and Inventory. Expand **Item cards** beside serial inputs, AFK item lists and in the editor to preview those codes too.

- Your uploaded screenshots and matching GZO images come first. Missing cards can use BL4's own card builder, then stay cached for reuse. Offline cached cards are labeled.
- Refreshing a large inventory no longer generates every hidden card. Only visible previews request images.
- Equivalent serial encodings can reuse GZO images while different levels, parts and part order remain distinct.
- Independent manual and AFK deliveries can run to different players, with overlapping deliveries to the same player protected.
- SDK checks and updates follow your selected game installation, and show installed versus loaded SDK identity separately.

New game-generated cards currently require the supported Steam build 25372571 in a solo session. They show standalone stats; equipped firmware counts and comparison context are not included. Some artwork and unusually long modded layouts remain incomplete. Existing screenshots remain usable without native generation. This release does not call NCS for card generation.

Android remains at v1.5.0. Install the desktop update and its matching SDK mod, then restart BL4 to load the new SDK.
