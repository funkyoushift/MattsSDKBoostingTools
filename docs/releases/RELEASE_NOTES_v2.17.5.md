# MSBT v2.17.5

- Adds prominent Support Development links on desktop and Android, leading to FunkYouSHiFT’s official PayPal, Cash App, and Venmo options. Matt’s separate support link remains available.
- Adds reusable MSBT-Setup.exe: keep this installer to install, repair, or update to the latest stable release. Downloads are checked against published sizes and SHA-256 hashes, with rollback on a failed replacement.
- Integrates Setup into desktop update controls. The previous versioned installer remains available for compatibility.
- Updates Android to 1.4.2 (29), retaining the existing application ID and signing key.

Setup installs per-user and leaves existing legacy installations intact. It does not modify game mods or stop Borderlands. The setup executable is unsigned.

Gameplay behavior is unchanged from v2.17.4. The reported AFK FPS issue and exact serial readback differences remain unresolved.
