### What's new

**v2.3.6** — QoL: XYZ bookmarks, Dev Spawner Compact/Panels, movement scope & peer teleports, Mobile Gateway tab.

#### Map Travel
- **XYZ Location Bookmarks** — save your current position, Go Selected / Delete Selected without map travel

#### Dev Spawner
- **Compact** layout by default (pick → spawn, one actor list, favorite strip)
- **Panels** toggle restores the multi-card dock layout; choice is saved locally

#### Player Movement
- Apply **scope**: Local / All / Others
- Peer teleports: **Selected → Me**, **Me → Selected**, **All → Me** (plus existing To P1–P4)

#### Mobile Gateway
- Dedicated **Mobile Gateway** main tab (fixed layout so the pairing QR stays fully visible)
- Pairing copy updated across install page / Android companion docs (no longer under Activity)

#### Walkthroughs
- Tab tours updated for XYZ bookmarks, movement scope/P2P, Compact|Panels, and Mobile Gateway

#### Upgrade notes

1. Install `MSBT-Installer-v2.3.6.exe` (or extract the portable ZIP).
2. Open Updates → **Install / Update SDK Mod** if needed.
3. **Fully restart Borderlands 4** so the SDK and bridge load.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3) (installable from MSBT Updates).
