# Unreleased candidate: mission replay and co-op completion repairs

This candidate is based on v2.38.1. Public downloads and version numbers are unchanged.

## Included

- **Mission replay:** one campaign-filtered selector, numbered in authored dependency order. Select any of39 supported story/DLC missions or506 main objective sections, including points beyond the current save. Automatic character unloading, backed-up inactive-save editing, native character reload and map refresh preserve current equipment and levels. Requires solo hosting and a second existing loadable character in the same profile.
- **Automatic starting locations:**326 source-derived preceding-waypoint candidates use native collision/grounding checks before placement;180 sections use native stations. Unsafe or unloaded waypoint coordinates also retain the native station and report the fallback. General Crystal Brawl placement and native-station fallback passed live tests. Individual encounters remain experimental.
- **Mission-state bookmarks:** capture a readable active mission after autosave. Restore its captured mission/world timeline and native respawn station while preserving current equipment and levels. Automatic bookmark reload passed a Dark Subject round trip. Broader changed-timeline encounter behavior remains experimental.
- **Dialogue skip:** the toggle uses normal native dialogue completion rather than audio interruption. Live conversation completion and persistence through map reload passed. Some authored timed scenes may still wait.
- **Co-op completion:** individual objectives and whole missions use the shared native objective graph, retaining the lobby binding through required map transitions. Completion does not teleport players to individual waypoints. Re-completing host-finished missions for visitors requires the visible reset option. Individual objective outcomes now check lobby DLC access before issue and during preparation.
- **Full-game content filtering:** the run requests each visitor’s real entitlement snapshot and waits for the normal server reply before mission work; it then reads native access again.  the original bulk mission-completion flow is retained, without replaying objectives or waiting through individual mission scenes. base-game work can proceed in a lobby of any supported size without everyone owning all DLC. Both native per-player access and actor/session attributes must confirm shared content. Missing, unknown or conflicting access skips that pack and leaves eligible work available. Pack reports identify affected players. Takedown mission entries now use the existing native Tuba content gate; no entitlement values are granted or changed.
- **Compatibility and other repairs:** Steam/Epic native profiles and Epic account save encryption are included, along with Shinies credential forwarding, per-player UVHM verification and the existing desktop control repairs. The repo audit found those completed repairs already present in this candidate; unrelated research/survey scripts were not bulk-merged.
- **Recovery:** uncertain native calls are journaled and never automatically repeated. Stop retains changes and backups. Restoring a full backup requires the original character to be unloaded and restores the entire earlier save.

## Validation and remaining verification

The co-op/content pass passed591 focused Python tests across36 modules,23 Node save-transaction/account-codec checks, the full-progress panel check, and both responsive mission/replay UI suites with stubbed actions. Tests cover two-/four-player shared completion, selected-objective isolation, roster changes, unavailable/conflicting DLC, source identity, movement policy and recovery.

Martin confirmed the installed replay update works. Previous native tests verified automatic save swap, general waypoint placement, fallback, bookmarks and normal dialogue completion. A full base-game mission completed in a live three-player lobby, and Martin confirmed both visitors received completion and rewards. Live access reports distinguished packs owned by one visitor and missing for others. Martin confirmed UDS_Prophet owns only bounty packs. A normal visitor entitlement refresh then correctly identified the unavailable larger story packs. Automatic refresh and the complete mixed-DLC run still need final live verification; visitor own-game save/quit/rejoin checks remain separate. The selected-composite initializer correction awaits its follow-up live test. A host mission state or a finished full-game run does not establish saved100% credit for every character. Epic support is included; Martin has accepted its implementation without requiring another Epic live-testing pass.

Mixed-DLC end-to-end verification is a release blocker. A live bulk pass completed189 eligible missions and deferred unavailable packs, but visitors still lacked the separate campaign-unlock challenge. The campaign-credit repair passed live native checks for both visitors; all25 UVHM challenge steps then completed for all three players. The automatic visitor-access refresh is installed for its final mixed-DLC run. Remaining full-progress stages and visitor save/rejoin proof are incomplete.
