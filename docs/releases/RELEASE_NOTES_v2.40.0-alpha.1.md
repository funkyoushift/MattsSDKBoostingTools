# Linux desktop preview — 2.40.0-alpha.1

Native Linux x86-64 desktop with bundled Python and PyYAML. Extract the tar.gz and run ./msbt. No Node/Python installation needed. Linux Steam library discovery, Proton game-running protection, ZIP extraction and Python paths are supported. Updates use manual archive replacement. Search now keeps the selected control visible when walkthrough highlights reposition on scrolling.

**Experimental:** solo Proton startup, exact SDK identity, live bridge communication and a reversible third-person on/off command passed on Steam build26007962. The user also confirmed the camera/F7 menu/panel check and additional hands-on controls looked good. Broad gameplay, multiplayer and save persistence remain unverified. Borderlands 4 and the SDK still run as Windows software under Proton. Close the game before installing SDK components. Save replay requires an explicit MSBT_SAVE_ROOT; see the included LINUX-README.md. Existing v2.39.9 game/save/trophy limitations remain.

## Download

- MSBT-Portable-v2.40.0-alpha.1-linux-x64.tar.gz — Linux desktop, resources and bundled full SDK.
- MattsSDKBoostingTools.sdkmod — optional manual installation of the same full SDK. Do not install alongside standalone Mission Selector.
- SHA256SUMS.txt — checksums.

Windows and Android users should continue using stable v2.39.9; this preview does not replace their update channel. Standalone Mission Selector remains available from v2.39.9 and is separate from this Linux preview. Source archives are for development.
