# Borderlands 4 Modding Tools v2.24.0

- Send items to your own backpack while visiting another player's lobby on supported Steam and Epic builds.
- Guest delivery uses the same size-based chunks and pacing as host delivery.
- Drop My Backpack works on your own character when hosting or visiting a lobby. Drop requests are submitted together.
- Guest actions stay limited to your own character. Existing host behavior and bulk-delivery authorization remain in place.

Update the desktop app and SDK mod together. Android remains on version 1.5.0.
