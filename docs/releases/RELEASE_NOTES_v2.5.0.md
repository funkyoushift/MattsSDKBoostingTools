### What's new

**v2.5.0**

- **Hoard Builder** (new tab) — build multi-enemy waves, click actors to add them, **Start Hoard**, clear-when-dead auto-advance through waves, plus **Stop** / **Clear**; walkthrough tutorial on the tab / app tour
- **Dev Spawner → Hoard Builder** — shortcut from Dev Spawner into the Hoard Builder tab
- **Quick Menu** — assignable `hoard_start` / `hoard_stop` / `hoard_clear` actions
- **Reset Skill Tree** (Dev Tools) — party target / All / Non-Host; Specializations are not reset
- **Instant Drops** reliability — Outer-aware re-apply so the toggle sticks more reliably; if you previously installed the standalone InstantClickHolds mod, remove it from the load path (Instant Drops / Instant Holds live in MSBT)

### Upgrade notes

1. Install `MSBT-Installer-v2.5.0.exe` (or extract the portable ZIP).
2. Open Updates → **Install / Update SDK Mod** if needed (also refreshes bundled ActorScriptDeployer).
3. **Fully restart Borderlands 4** after the SDK install so the SDK and bridge load.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3) (installable from MSBT Updates).
