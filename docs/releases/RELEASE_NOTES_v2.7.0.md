### What's new

**v2.7.0**

- **UI and workflow overhaul** — clearer fixed-page and dockable-panel workspaces, denser responsive layouts, and better low-resolution behavior
- **Boosting Essentials** — frequent actions, UVH controls, Shinies Drop / targeted Deliver, Instant Actions, and Debug Camera now share one practical home
- **Safer backpack drop** — Drop All Backpack is explicitly host-only, independent of the selected Boosting target
- **Combat & Cheats organization** — enemy, XP, currency, loot, and helper actions are grouped together
- **Layout controls** — Fixed / Panels mode where supported, Comfortable / Compact spacing, clearer packing and reset behavior, and refreshed Boosting defaults
- **Finer panel snapping** — 48 columns and 18px rows provide quarter-step resizing while existing saved layouts migrate at the same visual size
- **Fullscreen restore fix** — leaving fullscreen restores the prior Windows bounds, including half-screen snaps
- **Walkthrough refresh** — all 88 highlighted steps were audited against the current DOM; stale Quick Max, status, panel, layout, and Shinies wording was removed
- **Hoard Builder guidance** — guided wave building, automatic advancement, favorites, and Emergency Clear safety
- **Persistent Dev Tools** — Dev Spawner layout choices and tool state survive restarts
- **BL4 Codes browsing** — sticky delivery controls and denser cards keep catalog actions available while scrolling

### Upgrade notes

1. Existing panel layouts migrate automatically; **Reset layout** applies the refreshed defaults.
2. Open Updates → **Install / Update SDK Mod** if needed.
3. **Fully restart Borderlands 4** after the SDK install.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
