# MSBT v2.19.1

Saved Items now follows a folder → select items → send workflow for both your own bookmarks and the community library.

- Browse local and community folders as Inventory-style item cards, loaded as you scroll.
- Select one, multiple, or all items from an approved community folder and send them directly, without importing first.
- Choose the delivery target, copies, and optional item-level override in one shared delivery panel.
- Switching local folders clears the previous selection and shows the chosen folder. Long folder names wrap fully.
- Folder management, item-code editing, and sharing tools stay available in expandable sections.
- Direct inventory delivery finishes with a 3-second settlement wait instead of 30 seconds.

Saved serials and duplicates are preserved. Cards use the existing Inventory renderer; unresolved details are not new claims of exact game parity. Delivery progress confirms host submission, not the guest's saved inventory.

The installer continues bundling the SDK mod and required AFK PAK for Steam and Epic installations. Android remains v1.4.2.
