# Borderlands 4 Modding Tools v2.25.0 — Powered by Funk

Community folders now display uploaded item screenshots and GZO titles/images when the complete item code matches exactly. Uploaded screenshots take priority, and unmatched items keep their saved names without an invented card preview.

- Imported community items retain their screenshot links, GZO titles, and original saved labels.
- Changing an imported item code prevents an unrelated screenshot from being shown.
- Community browsing requests up to 100 folders per page while retaining search and previous/next navigation.
- The website supports screenshot uploads and reviewed image changes; the public API exposes the same presentation metadata.
- Includes all v2.24.0 fixes and language support. Android remains v1.5.0 with the existing verified APK.

Screenshots are online references and may become unavailable if their source is withdrawn. This update does not claim native generated item-card accuracy or change live game delivery behavior.
