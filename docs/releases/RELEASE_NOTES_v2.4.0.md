### What's new

**v2.4.0**

- **Instant Drops** — menu-arm / client-local toggle so drops resolve without the usual wait
- **Instant Holds** — separate toggle for UI / skill / world hold prompts (independent from Instant Drops)
- **Extreme Combat XP** — host-side combat XP multiplier (Boosting → Quick Max)
- **Clear Fog of War** — hide fog materials / clear map fog from Quick Max and Quick Menu
- **Dev Spawner Compact** — fixed-layout actor list and controls keep usable scrollbars
- **Vehicle tuning** — vehicle preset / spawn QoL on the live bridge path
- **Max All / boosting QoL** — Quick Max and related boost actions remain first-class

**Not in this release**

- **Hoard Builder** (wave runner UI + SDK runner) is intentionally excluded. Full snapshot remains on branch `wip/hoard-builder-v1` for a later ship.

### Upgrade notes

1. Install `MSBT-Installer-v2.4.0.exe` (or extract the portable ZIP).
2. Open Updates → **Install / Update SDK Mod** if needed (also refreshes bundled ActorScriptDeployer).
3. **Fully restart Borderlands 4** so the SDK and bridge load.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3) (installable from MSBT Updates).
