# MSBT v2.19.0

- Fixed direct inventory delivery rejecting the supported Epic Games build. The same SDK mod now recognizes Steam and Epic using separate verified function profiles.
- Added an AFK item-level override (1–70) for pooled and guaranteed loot. The setting is saved; original backpack items retain their existing levels.
- Made Community library and Share a folder prominent in Saved Items. Local items and online folders now have separate views, and folder-management tools are grouped together.
- Kept the bundled SDK manager and AFK SHiFT PAK installation, including explicit selection of an Epic or Steam game folder.

## Updating
Close Borderlands 4, update MSBT, and let setup install the bundled game mod. If multiple game copies are installed, use Choose game folder to select the intended copy. Restart the game after updating its mod.

## Verification
Epic and Steam function checks passed against the installed executables. Installer, delivery, AFK, and community UI checks passed. Epic live gameplay and guest-save persistence have not yet been confirmed; report delivery problems with the game build and exact error.
