### What's new

**v2.8.8**

- **Inventory Send to Game** can keep an item's level or override it (1–70), same rewrite as Serial Rewards
- Inventory cards populate item names more reliably from the GZO parts list
- **Apply Fly Speed** writes once on click (no per-frame hooks); landing restores your previous walk speed
- **Third Person** toggle on Boosting Essentials (client-local, pin-able to F7). Disable the standalone Third Person zip while this is on — double hooks can crash

### Upgrade notes

1. Open Updates → **Install / Update SDK Mod**, or copy the packaged `.sdkmod` into `sdk_mods`.
2. **Fully restart Borderlands 4** after the SDK install (this release adds new SDK modules).
3. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
