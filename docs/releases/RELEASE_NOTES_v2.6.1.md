### What's new

**v2.6.1**

- **Drop All moved to Boosting** — the whole-backpack drop action now lives beside the Boosting backpack/bank controls instead of the hidden Dev Tools tab
- **Quick Menu consistency** — fresh F7 layouts include **Drop All**, and the action remains available in the Quick Menu editor

### Download: pick ONE

**Recommended for almost everyone**

Download and run:
- `MSBT-Installer-v2.6.1.exe`

**Manual install / portable Electron app**

Download and extract:
- `MSBT-Portable-v2.6.1-win-x64.zip`

**Do not manually download these unless you know why**

- latest.json, latest.yml, *.blockmap

### Upgrade notes

1. Install `MSBT-Installer-v2.6.1.exe` (or extract the portable ZIP).
2. Open Updates → **Install / Update SDK Mod** if needed.
3. **Fully restart Borderlands 4** after the SDK install.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
