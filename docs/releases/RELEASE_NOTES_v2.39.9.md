# v2.39.9 — Support links and saved choices

FunkYouSHiFT development-support buttons in the Windows app, Android companion and GitHub funding metadata now open [Buy Me a Coffee](https://buymeacoffee.com/funkyoushift). The website donation page uses the same destination and a verified QR code. Mattmab's independent Ko-fi link, St. Jude charity links and merch remain separate.

The desktop app tour now suppresses itself for the current version only when “don't auto-show” is checked. Leaving it unchecked offers the tour again on the next launch. The mobile-app announcement also retains its choice when closing or opening Mobile Gateway, and users can change that choice when reopening the announcement. Saved movement and rarity presets were checked across app restarts.

This patch retains v2.39.8's Full Game recovery. Mission replay, Full Game completion, Epic gameplay and guest-save limits from that release remain unchanged; this update does not claim 100% trophy or save proof.

Android 1.6.6/build 39 includes the new support destination and the existing pairing repair. The standalone Mission Selector is repackaged with matching version metadata; use it instead of the full-app SDK, not alongside it.

## Downloads

- **Windows:** `MSBT-Installer-v2.39.9.exe` or `MSBT-Portable-v2.39.9-win-x64.zip`.
- **Full app SDK:** `MattsSDKBoostingTools.sdkmod`, also bundled with Windows.
- **Standalone selector:** `BL4MissionSelector.sdkmod`.
- **Android:** `MSBT-Mobile-Controller.apk`, version 1.6.6.

Close Borderlands 4 before replacing SDK files. Existing saves and replay backups stay on the PC.
