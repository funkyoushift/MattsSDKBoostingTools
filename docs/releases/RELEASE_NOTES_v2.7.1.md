### What's new

**v2.7.1**

- **Clear multi-select workflows** — Inventory, Hoard Builder, Dev Spawner, and Serial Bookmarks now have an explicit Select Multiple mode, shared red selection highlighting, and familiar Ctrl/Cmd + Shift shortcuts
- **Faster Hoard browsing** — the actor picker starts with an enemies-only catalog, can reveal advanced entries with Show all actors, and virtualizes the full list for responsive scrolling
- **Reliable text scaling** — View text size now applies consistently to Fixed pages and Dev Spawner as well as docked panels
- **Instant action shortcuts** — Instant Drops and Instant Holds expose direct oak2 keybinds and can be pinned into the in-game Quick Menu with per-slot hotkeys
- **Cleaner Boosting organization** — Essentials, Combat & Cheats, Instant Actions, and Debug Camera guidance matches their current locations
- **Walkthrough audit** — all 88 highlighted targets pass the automated DOM audit, with coverage for the new selection, Hoard, text-size, and instant-action guidance

1. Open Updates → **Install / Update SDK Mod** to receive the Instant Drops / Instant Holds keybind changes.
2. **Fully restart Borderlands 4** after the SDK install.
3. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
