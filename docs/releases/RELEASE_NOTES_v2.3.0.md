### What's new

**v2.3.0** — Mobile Gateway desktop + open-beta phone controller, home install QR, and a compact header.

#### Mobile Controller (open beta)
- Desktop **Mobile Gateway** (LAN) so the Android companion can drive Boost, Codes, Quick Menu, Control, and Spawn
- QR pairing from **Activity → Mobile Gateway**
- Home announcement popup with install QR → open-beta APK download
- Boosting home strip: **Show install QR** / **Mobile Gateway**
- Header **Mobile App** button to reopen the announcement

#### Compact header
- Tighter header padding and title/tagline sizing
- Support / donate links start **collapsed** by default
- Compact Support dropdown with shorter Tip / Donate / Discord / Twitch (and related) chips

#### Upgrade notes

1. Install `MSBT-Installer-v2.3.0.exe` (or extract the portable ZIP).
2. Run **Install / Update SDK Mod** from the app Updates tab.
3. **Fully restart Borderlands 4** so the bridge and live actions load.
4. Phone: install the [Mobile Controller APK](https://github.com/funkyoushift/MattsSDKBoostingTools/releases/download/mobile-beta/MSBT-Mobile-Controller.apk) (Android 9+), then pair via Activity → Mobile Gateway on the same Wi‑Fi.
5. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
