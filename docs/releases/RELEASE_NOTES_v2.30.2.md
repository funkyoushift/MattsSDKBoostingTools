## Changed

- Saved Items now confirms delivery inside the app, removing the Windows confirmation step associated with earlier keyboard-focus problems.
- Password and delivery dialogs use explicit theme colors, constrained widths and scrolling for smaller windows.
- Item Catalog continues to use its in-panel confirmation and receives the shared password-dialog styling improvement.

## Validation

Saved Items and Item Catalog passed automated visibility, typing, cancellation and authorization checks in Workspace and Classic layouts. The originally reported blank-white popup was not reproduced, so these checks do not establish that every reported occurrence is resolved. No live items were delivered during validation.

## Downloads

Use **MSBT-Installer-v2.30.2.exe**, or extract **MSBT-Portable-v2.30.2-win-x64.zip**. **MSBT-Setup.exe** installs the latest version.

Android companion remains the unchanged 1.5.1 build. SDK version metadata is coordinated with this desktop patch; gameplay behavior is unchanged.
