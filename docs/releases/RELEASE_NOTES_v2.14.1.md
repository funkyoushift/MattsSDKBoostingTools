# AFK settings and walkthrough

AFK Lobby now has independent **UVHM 1–7** and **All Customs + Hovers** checkboxes, both off by default. Non-UVHM challenges remain separate. All Customs + Hovers uses the same game action as the Boosting tab button, targeted at each joining guest.

UVHM uses the existing tier sequence and pacing. AFK waits for its final step to settle before continuing; a reported failure prevents auto-kick. Leaving or stopping cancels unfinished AFK work.

A new **AFK Lobby walkthrough** explains setup, boost selections, adding loot from Item Catalog and bookmarks, auto-accept, auto-kick, starting, stopping, and restoring game controls. Open it from the AFK panel or tutorial chooser.

The installer continues to include the SHiFT PAK and official SDK/mod manager, preserving existing SDK/manager installations including beta versions. Close Borderlands 4 before installing the game update.

**Known limits:** SHiFT must stay open for auto-accept and captures gameplay controls. Guest save persistence and 100% challenge completion are not confirmed by a finished queue. The new settings passed offline routing and UI tests; live guest verification remains outstanding.
