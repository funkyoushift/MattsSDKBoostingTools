### What's new

**v2.3.1** — Phone-friendly Mobile Controller install page for the home QR.

#### Mobile install QR fix
- Home announcement QR now opens a mobile install landing page (not a raw GitHub APK URL)
- Landing page has a large **Download APK** button plus install / pairing steps
- Modal copy clarifies **install QR** vs **pairing QR** (Activity → Mobile Gateway)

#### Upgrade notes

1. Install `MSBT-Installer-v2.3.1.exe` (or extract the portable ZIP).
2. Run **Install / Update SDK Mod** from the app Updates tab.
3. **Fully restart Borderlands 4** so the bridge and live actions load.
4. Phone: open the [Mobile install page](https://www.funkyoushift.com/MattsSDKBoostingTools/mobile-install.html), tap **Download APK**, install, then pair via Activity → Mobile Gateway on the same Wi‑Fi.
5. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
