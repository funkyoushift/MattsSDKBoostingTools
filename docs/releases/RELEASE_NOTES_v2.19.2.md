# MSBT v2.19.2

Saved Items makes better use of large windows while staying usable on smaller screens.

- Local and community item lists grow with the window height instead of stopping at fixed heights.
- The community folder column leaves more width for item cards.
- Smaller windows keep stacked layouts and bounded scrolling areas.
- Item cards fit narrow views without horizontal overflow.

Layout and selection checks passed from 480 to 2560 pixels wide. Includes the existing v2.19.1 item-card browser and 3-second delivery settlement. SDK behavior and Android v1.4.2 are unchanged.
