### Upgrade notes

1. Open Updates → **Install / Update SDK Mod**, or copy the packaged `.sdkmod` into `sdk_mods`.
2. **Fully restart Borderlands 4** after the SDK install (this release adds/keeps in-game Phone Pairing).
3. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
4. Phone users on an older mobile beta: install **over** the previous APK so pairing data survives. Then Check for updates in More → About.
