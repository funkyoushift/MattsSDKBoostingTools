# Matt's SDK Boosting Tools v2.13.0

Includes Android controller v1.2.0.

### Boosting and editor fixes

- Correct Max All specialization, customization, vehicle, and vault-card key delivery.
- Fix edited save-file writeback, repeated serial-code sends, custom hotkeys, Black Market spawning, and reopening the Golden Chest.
- Add live selected-player level, specialization, currencies, and vault-card readback.
- Make the editor delivery panel collapsible and improve navigation and challenge-log layout.

### Codes and mobile controls

- Expand GZO search filters and pagination, highlight code submission, and improve the submission form and image handling.
- Restore complete item-pool lists and Pearl pool filters.
- Bring mobile boosting scopes, challenges, convenience actions, live readback, and code filters closer to desktop.
- Prevent stale player selections and delayed responses from targeting the wrong player.
- Add mobile GZO submission through the paired desktop gateway. Direct SDK pairing remains available for normal game controls.

### Download

- Windows: **MSBT-Installer-v2.13.0.exe** (recommended), or **MSBT-Portable-v2.13.0-win-x64.zip**.
- Android: **MSBT-Mobile-Controller.apk**. Install over the existing controller to retain its settings.
- Requires oak2-mod-manager v0.3.

### Validation and scope

The reported gameplay fixes and phone experience were tested with Matt. Automated checks cover targeting, readback, catalogs, delivery, and gateway submission handling; no public GZO test submissions were posted.

Unfinished native item-card rendering research, cooldown changes, and enemy-level features are not included in this release.
