# Borderlands 4 Modding Tools v2.22.0 — Powered by Funk

## Languages on desktop and Android

- Choose English, Spanish, French, Brazilian Portuguese, German, or Dutch. Your choice stays selected after reopening the app.
- Expanded translation coverage throughout desktop and mobile controls, including changing status messages and tooltips.
- Reviewed 391 phrases for their meaning in the game: Max, party, kick, item codes, spawning, loot collections, and more.
- Optional **Australian slang (explicit)** adds deliberately profane English labels. Select it yourself; regular English stays unchanged.
- Player names, saved folder names, item codes, and game logs stay untouched. This translates the app interface, not the native F7 game menu.

## Help improve the wording

Speakers of each supported language are invited to review the translations and send feedback through **Help & Report an Issue**, GitHub, or the community Discord. Please include the chosen language, the screen or button, the current wording, and your suggested wording. A screenshot helps. The catalog includes automatic translations and has not had a full native-speaker review.

## Downloads and validation

Windows v2.22.0 and Android v1.5.0 ship the same language catalog. Update the Android app to receive these changes there. Desktop/mobile language, persistence, responsive-layout, data-preservation, and AFK interface checks passed. No gameplay behavior was changed by this language update.
