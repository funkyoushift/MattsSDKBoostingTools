# v2.35.1 - Desktop layout cleanup

Tools are organized by task, with a Home directory, clearer categories, Back navigation, and player selectors beside the controls that use them. Existing Mayhem 1-20 and AFK Mayhem features remain included.

- Separate pages for progression, survival, movement, camera, ground loot, vendors, and Party & AFK.
- Consistent item-to-AFK shortcuts for catalog, saved/community items, inventory and serial tools. Preparing a list does not start AFK or send items.
- Hover cards no longer block clicking the next item. Open View Card for interactive zoom and scrolling.
- Clearer control labels, scope explanations and disconnected-state guidance. Classic layout remains available.

Validation covers all 40 navigation routes, targeting payloads, AFK handoffs and edit locks, hover interactions, search and responsive layout. Packaged checks are recorded in the release verification receipt.

This release does not fix the shiny-skin failure in the Takedown combat area or implement whole-game mission completion. Android 1.6.2 is carried forward unchanged; the new layout is for Windows. The SDK version advances in lockstep without gameplay changes from 2.35.0.
