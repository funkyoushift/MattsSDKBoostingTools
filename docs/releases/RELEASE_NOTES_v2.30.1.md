## Added

- A dedicated Credits tab with contributor acknowledgments, original project links, community Discords, and offline third-party notices.

## Changed

- Consolidated credits into one place and removed repeated acknowledgments from feature panels.
- Corrected contributor attribution, including Mattmab’s original toolset and Actor Script Deployer, Squ1ggs’ later helper contributions, Azalea’s UVH workflow, and Pyrex’s Bonk Utilities.
- Improved SDK packaging so a failed build preserves the previous package.
- Excluded development tests and caches from desktop packages.
- Refreshed bundled attribution notices in Android companion 1.5.1.

## Removed

- The retired BLImGui panel and its startup fallback. The native F7 Quick Menu and external bridge remain supported.
- Obsolete screenshots, preview notes, and development-only repository files.

## Downloads

Use **MSBT-Installer-v2.30.1.exe**, or extract **MSBT-Portable-v2.30.1-win-x64.zip** for the portable app. The reusable **MSBT-Setup.exe** installs the latest version.

This maintenance update does not add new gameplay features. Live gameplay was not revalidated for this patch.
