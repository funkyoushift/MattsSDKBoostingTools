# Live editor cards and clearer item previews

- Matt Editor now shows a live item card beside the editor. It updates after edits settle, reuses cached images, and renders one selected item at a time. Automatic updates can be paused, and the card can be opened and zoomed for reading.
- New game cards can generate while guests are present. The solo-only restriction has been removed; supported game-build and game-thread checks remain.
- Heavily modded cards use an expanded layout when compact text overflows. Cropped thumbnails open into full, scrollable, zoomable previews; compact layout remains available.
- Non-GZO saved and community items display resolved game-card names while keeping original labels searchable. GZO names remain intact, including when their screenshots are unavailable.
- Fixed missing grenade artwork and a rendering failure caused by input-button markup. Firmware identities are displayed without attempting equipped-loadout effect calculations.
- The community website now serves 2,831 stored game cards with the same enlarged viewing controls. Website visitors do not need a running game.

## Upgrade

Update the desktop app and bundled game mod, then restart Borderlands 4 to load the new mod. Existing uploaded screenshots and GZO cards remain preferred. Newly generated cards require a supported running game; cached cards remain available offline.

## Known limitations

Multiplayer card generation is newly enabled and has not been validated in a live guest session. Cards show standalone item data, not equipped-loadout or comparison effects. Six community codes failed native construction/export. Some cards show an explicit unresolved input action instead of a guessed keyboard/controller button. These changes do not claim perfect parity for every possible modded item.

The Android controller remains version 1.5.0, with unchanged APKs.
