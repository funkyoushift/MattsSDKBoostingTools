# MSBT 2.41.0 — SHiFT background controls

This release adds a compact, visible SHiFT background view with an authenticated local companion, plus AFK God Mode controls. Background polling can continue while you move and look around in the supported Steam build. The SHiFT panel remains visible; this is not an invisible mode. Other game builds fail closed for this native path.

The native background observer was exercised for 60 seconds with 31 active samples, 22 polls, 42 responses, and no errors. Martin confirmed normal walking and mouse look with the compact panel visible and the cursor hidden. AFK God Mode start and stop were verified, including restoration of normal damage behavior. The native view was also stopped and restored without an error.

The desktop Start, Show, and Stop controls were tested on a prior snapshot. Protected-list storage was checked across save and reload. The build's Python startup/import and SDK archive checks passed. These checks do not establish support for other game builds or an invisible SHiFT view.

Android remains unchanged. Close Borderlands 4 before replacing the SDK mod.
