   including native checkpoint references, source pointers/hashes, active internal
   steps, grounded movement and prior completion context. A starting point is used
   only when its group AND selected main-objective identity match the catalog.

   Ripper Queen and Mountains 1's opening. The separately observed HackDoor / later
   FindBoss records are retained but not silently remapped onto another section.

   the chosen main objective still to be active before placement. A loaded,
   walkable capsule floor is required for every player. Recorded placement never
   falls back to a flying/movement hold or guessed station. Native rejection stops
   the run without retrying. Normal movement and location are read back afterward;
   custom movement settings are captured and restored even when teleport rejects
   or throws. Applied partial placements remain explicitly uncertain.
   These starts remain **amber / experimental**, not verified replay spawns.

5. **Dialogue skip.** Session-only on/off control in Missions, plus shared backend
   actions available to F7/mobile. Uses the existing shared camera update pump at
   a bounded cadence and the existing native DialogueSkipper helper; no additional
   camera hook, worker, time dilation or persistent preference. Host/solo only;
   default off, removed on mod disable, fresh world scope after travel. Errors
   disable it without retrying the uncertain native call. Spoken dialogue affects
   the whole lobby; cinematic/script waits may remain. Yeti attribution remains
   in THIRD_PARTY_NOTICES. Desktop has explicit on/off state and a status check.

6. **UVHM.** All 25 challenge identities and one-count goals match hashed extracted
   game definitions. The configured order satisfies internal prerequisite order;
   ranks 2–7 explicitly name the expected completion and preceding levels.
   Rank 1's extract omits its numeric completion default; no invented default was
   added. Existing plan and pacing retained, including ranks 6 and 7.
   Audit: `tools/mission_lab/data/uvhm_catalog_audit.json`.
   Failed RPCs / disappeared targets stop as uncertain; zero-target queues cannot
   drain as success. Late players cannot receive only a plan's tail. Discovery is
   limited to the loaded world; resume retains original players and never substitutes
   a new lobby. Repeated Cancel preserves paused work. Travel discards old target
   wrappers and stops for inspection. Full-progress propagates uncertainty.
   Successful queue text says **requests sent**, not saved unlocks verified.

7. **Additional AFK bug found and repaired.** The Game adapter sends UVHM privately

   guests. Only genuinely shared challenge runs now share that credit. Each guest
   receives their full private UVHM sequence, including late guests. Failed UVHM
