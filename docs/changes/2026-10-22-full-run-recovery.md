## Repair

`backend_actions.py` and `full_progress_runtime.py` discard only the unsent tail of an uncertain UVHM queue, or explicitly replace other pending work when the operator selects Run anyway. `full_progress.py` records that cleanup in the new run journal. The desktop Full Game panel exposes the explicit replacement option.

For Full Game only, `mission_challenges.py` and `mission_progression.py` defer a pre-callback native credit readback mismatch for the affected player, journal that player's identity, and continue checking other party members and later missions. Manual mission operations keep the strict stop. The final pass rechecks deferred credit for the same player and reports it as unverified if it still disagrees. It does not forge challenge bits or report full completion. An already-issued final-pass credit callback is reconciled before cancellation or recovery, and is never reissued while pending.
