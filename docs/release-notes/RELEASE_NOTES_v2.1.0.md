### What's new

**v2.1.0** — Redesigned in-game Quick Menu, rarities sync, and a fuller first-run walkthrough.

#### Quick Menu
- Azzy-inspired in-game Quick Menu: right-docked panel, MOVE / THEME / resize, stronger theme contrast, and outlined text for readability
- Slot grid is now **3×7** (21 slots per page)
- Optional **rarity weight** strip can be equipped or unequipped from the ★ Quick Menu editor
- Pull Loot / Super Dash helpers available from Boosting and Player Movement with **+ QM**
- Editor fixes: page selection and custom labels no longer reset while editing

#### Rarity weights
- In-game rarity sliders live-apply like the original BLImGui card and persist settings
- Boosting-tab sliders stay in sync with the Quick Menu (shared backend weights)

#### Walkthrough
- Expanded first-run / replay tour covering + QM pins, including Item Pool and Dev Spawner
- Calls the panel the **Quick Menu**; F7 is only mentioned as the in-game open hotkey

### Upgrade notes

1. Install `MSBT-Installer-v2.1.0.exe` (or extract the portable ZIP).
2. Run **Install / Update SDK Mod** from the app Updates tab.
3. **Fully restart Borderlands 4** so the new Quick Menu and rarity sync load.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
