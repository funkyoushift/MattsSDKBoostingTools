### What's new

**v2.0.2** — Expanded Map Travel, favorites, shinies, and challenge tooling.

#### Map Travel
- Expanded travel catalog (more maps and stations, including DLC where installed)
- Unified **favorites** for maps and stations — rename, travel, and remove from one list

#### Loot / Boosting
- **Drop All Shinies** pool support
- Muted Boosting **do not click** control for queued challenge completion (Shift/Ctrl as documented in-app)

#### Data
- Synced travel/station catalogs, shiny pools, and challenge catalog into the SDK mod package

### Upgrade notes

1. Install `MSBT-Installer-v2.0.2.exe` (or extract the portable ZIP).
2. Run **Install / Update SDK Mod** from the app Updates tab.
3. **Fully restart Borderlands 4** so the new travel/shiny/challenge actions load.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).

### Download: pick ONE
