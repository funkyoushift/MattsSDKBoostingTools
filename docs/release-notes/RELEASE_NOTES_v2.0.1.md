### What's new

**v2.0.1** — Quick Menu close fix and clearer pin workflow docs.

#### Fixes
- **F7 closes the Quick Menu** while the menu owns UI focus (polled like Esc)
- Debounce so open/close hotkeys do not fight and reopen instantly
- Close button labeled **Close F7**
- Dock hint: `F7 close · Esc close modal · F6 unstuck`
- **F6 Unstuck** toast explains it force-closes the menu and restores mouse/look/move

#### Docs / media
- README Quick Menu section with screenshots of the editor and `+ QM` pin buttons
- Discord media close-ups for Serial Bookmarks / BL4 Codes / Boosting pins

### Upgrade notes

1. Install `MSBT-Installer-v2.0.1.exe` (or extract the portable ZIP).
2. Run **Install / Update SDK Mod** from the app Updates tab.
3. **Fully restart Borderlands 4** so the F7 close fix loads.
4. Requires [oak2-mod-manager v0.3](https://github.com/bl-sdk/oak2-mod-manager/releases/tag/v0.3).
