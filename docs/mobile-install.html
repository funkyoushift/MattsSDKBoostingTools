Install MSBT Mobile Controller

Android open beta. Tap Download, then open the APK from Chrome’s download notification to install. This page is the install link — pairing uses a different QR inside the desktop app.

Download APK

Android 9+ · about 6 MB · open-beta build

  1. Tap Download APK above.
  2. When Chrome finishes, open the download (notification or Downloads list).
  3. Allow install from Chrome / Files if Android asks.
  4. On PC: MSBT → Activity → Mobile Gateway.
  5. In the phone app: Scan QR to pair (that QR is for pairing, not this install page).

Same Wi‑Fi as the gaming PC is required for pairing. Reinstalling over a previous beta keeps local data.
